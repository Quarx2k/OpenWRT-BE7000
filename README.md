# BE7000-OpenWrt

**English** · [Русский](README.ru.md)

OpenWrt **25.12.5** for Xiaomi BE7000, based on [Linux 5.4.164](https://github.com/Quarx2k/OpenWRT-BE7000/tree/kernel-qsdk-12.1-r5). Boots from a USB drive using **kexec**. All router features are supported.

![LuCI on BE7000](images/luci-overview.png)

**[Download the latest release](https://github.com/Quarx2k/OpenWRT-BE7000/releases/latest)** — Windows and Linux installers, and an upgrade image.
