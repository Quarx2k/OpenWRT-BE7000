# BE7000-OpenWrt

[English](README.md) · **Русский**

OpenWrt **25.12.5** для Xiaomi BE7000 на базе [Linux 5.4.164](https://github.com/Quarx2k/OpenWRT-BE7000/tree/kernel-qsdk-12.1-r5). Загрузка с USB-накопителя через **kexec**. Все функции роутера работают.

![LuCI на BE7000](images/luci-overview.png)

**[Загрузить последнюю версию](https://github.com/Quarx2k/OpenWRT-BE7000/releases/latest)** — установщики для Windows и Linux, образ для обновления.
